## Description

[i-SATA](https://doi.org/10.21979/N9/5W3RIM) is an individual-brain extension of SATA for estimating current density generated by transcranial direct current stimulation (tDCS). SATA was developed for standardized headspace analyses; i-SATA extends this approach to individual head models so researchers can estimate current density across cortical lobes and gyri for a participant's own brain.

i-SATA is a MATLAB-based toolbox designed for use with individual T1-weighted MRI images and ROAST simulation outputs. It converts ROAST outputs to Talairach space using the anterior commissure (AC), posterior commissure (PC), and mid-sagittal (MS) points, supporting individualized analysis of tDCS montages and inter-individual variation in current density.

The i-SATA method is described in the lab's [Journal of Neural Engineering publication](/publication/2020_isata/).
